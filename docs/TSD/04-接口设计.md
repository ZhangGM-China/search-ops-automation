# 04 接口设计

| 字段 | 日期 |
| --- | --- |
| 创建时间 | 2026-07-23 |
| 最后更新时间 | 2026-08-18 |

本章是接口契约总入口。查一条接口时，先用全量路由清单确认它是否存在、暴露级别和归属专题页，再到专题页阅读请求、响应和调用边界。

| 层级 | 作用 | 事实源 |
| --- | --- | --- |
| 人读契约 | 环境、鉴权、通用协议和各业务域接口 | 本章下的 01～11 专题页 |
| 外部机器契约 | 外部只读与外部计算 allowlist | `src/api/contracts.py` 生成的 `api/openapi.json` |
| 全量路由事实 | 实际装配的 method/path、暴露级别和代码位置 | `src/api/application/*.py`、`src/api/routers/health.py` 生成的 `api/internal-api-inventory.md` |
| 前端调用 | 管理端实际参数和返回类型 | `frontend/src/shared/api/index.ts` |

`src/api/app.py` 只负责装配。内部路由尚未全面使用 `response_model`，其字段表必须与当前处理函数和前端调用保持一致。
