## 2. 最小调用

### cURL

```bash
export AIOPS_BASE_URL='https://ops.example.test/api'
export AIOPS_TOKEN="<from-controlled-secret-provider>"
curl --fail-with-body \
  "$AIOPS_BASE_URL/dashboard/top-query/overview?date=2026-07-23" \
  -H "Authorization: Bearer $AIOPS_TOKEN"
```

### Python

```python
import requests

response = requests.get(
    "https://ops.example.test/api/dashboard/top-query/overview",
    params={"date": "2026-07-23"},
    headers={"Authorization": "Bearer <issued-jwt>"},
    timeout=(3.05, 20),
)
response.raise_for_status()
data = response.json()
```

## 3. 版本与发布事实

| 项目 | 当前约定 |
| --- | --- |
| URL 版本 | 当前没有 URL 版本前缀；不得自行添加 `/v0` 或 `/v1`。 |
| 外部机器契约 | `src/api/contracts.py` 生成 `api/openapi.json`，由 Release Gate 检查漂移。 |
| 发布身份 | `releaseSha`、`schemaRelease`、`artifactManifestSha256` 等身份字段由健康摘要按当前发布注入；发布状态以[生产发布指南](../../production_deployment_guide.md)为准。 |

不要根据前端历史 URL 推断 API 契约。日期、扩展字段和错误处理统一见 03。

## 4. 健康接口

### 4.1 接口索引

| 方法 | 路径 | 鉴权 | 用途 |
| --- | --- | --- | --- |
| GET | `/api/health/live` | 无 | 进程存活探针。 |
| GET | `/api/health/startup` | 无 | 启动状态探针。 |
| GET | `/api/health/ready` | 无 | 数据库、运行时和启动就绪探针；部署内部探针。 |
| GET | `/api/health` | 无 | 健康摘要；属于外部只读 allowlist。 |

### 4.2 `GET /api/health`

#### 请求

- 参数：无。
- 副作用：只读；数据库探针有并发互斥和短超时，不触发治理任务。

#### 成功响应

HTTP `200` 表示健康接口本身可用；业务依赖异常通过响应字段表达，不以非 2xx 替代健康状态。

稳定顶层字段：

| 字段 | 类型 | 语义 |
| --- | --- | --- |
| `healthy` | boolean | 数据库、运行时、熔断、任务失败和新鲜度的综合结果。 |
| `releaseReadiness.ready` | boolean | 数据库连通且运行时可用、熔断关闭。 |
| `releaseReadiness.components.database.connected` | boolean | 数据库探针结果。 |
| `releaseReadiness.components.runtime.available` | boolean | 运行时可用性。 |
| `releaseReadiness.components.runtime.circuitClosed` | boolean | 业务接口熔断状态。 |
| `env` | string | 当前运行环境。 |
| `database.connected` | boolean | 数据库连通状态。 |
| `tasks.agentLoop` | object 或 null | 最近 Agent Loop 会话摘要。 |
| `tasks.serviceHealthCheck` | object 或 null | 最近健康巡检摘要。 |
| `runtime` | object | `OperationalService.get_runtime_status()` 的扩展区。 |

任务摘要稳定字段为 `taskName,status,phase,startTime,endTime`；实验质量存在时可附带 `experimentQuality`。发布身份字段由 `get_release_info()` 合并到顶层，消费者应透传未知字段。

```json
{
  "healthy": true,
  "releaseReadiness": {
    "ready": true,
    "components": {
      "database": {"connected": true},
      "runtime": {"available": true, "circuitClosed": true}
    }
  },
  "env": "prod",
  "database": {"connected": true},
  "tasks": {"agentLoop": null, "serviceHealthCheck": null},
  "runtime": {}
}
```

#### 错误与重试

- `healthy=false` 不等于接口不可达；继续读取 `database`、`runtime`、`tasks` 定位原因。
- HTTP `5xx`、超时、连接失败或无法解析 JSON 才表示健康接口不可用。
- 健康检查只允许有限 GET 退避，不能据此触发治理写操作。
