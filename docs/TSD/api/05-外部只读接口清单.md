# 05 外部接口清单

| 字段 | 日期 |
| --- | --- |
| 创建时间 | 2026-07-23 |
| 最后更新时间 | 2026-09-17 |

> 本页是外部 API allowlist，共 19 个只读 GET 和 3 个手工相关性检测 operation。除健康检查外均需 Bearer，并执行服务端品牌隔离；接口详情分别见 01、06、07、09 页。本页不承载内部接口契约。

## 1. 调用边界

- 生产 API Base URL：`https://ops.example.test/api`。
- 当前 FastAPI 不会自动把本表变成网关拒绝策略；网关接入时必须显式实现同一 allowlist。
- 机器可读契约为 [`openapi.json`](openapi.json)，Release Gate 会检查其与运行时外部契约的漂移。
- 本表不包含登录、管理、助理、Ops Team、Prompt、实验写入或任何治理动作接口。手工相关性检测只写内部任务状态，不执行拉黑、KG、治理记录或外部业务写入。

## 3. 共用协议

请求、响应、错误、分页、日期和有限重试统一见[03 通用协议、错误与流式传输](03-通用协议与错误契约.md)。机器字段和响应媒体类型以 [`openapi.json`](openapi.json) 为准。

## 4. 最小调用示例

```bash
curl --fail-with-body \
  'https://ops.example.test/api/dashboard/top-query/brands/atlas/queries?date=2026-07-23' \
  -H 'Authorization: Bearer <issued-jwt>'
```

## 5. 明确排除

以下接口不属于外部 allowlist：所有 `/api/admin/**`、除手工相关性检测外的 POST/PUT/PATCH/DELETE、`/api/ops-team/**`、`/api/assistant/**`、Prompt draft/publish/test、实验 draft/schedule/end/cancel、治理运行触发，以及 approve/execute/reject/rollback/mark-processed/cancel/toggle 路径。
