> 本页覆盖 5 个 `external-read` GET，全部需 Bearer。带 `{brand}` 的接口校验路径品牌；带 `{experiment_id}` 的接口先读取实验归属品牌再校验。

## 1. 接口索引

| 方法 | 路径 | 鉴权 | 用途 |
| --- | --- | --- | --- |
| GET | `/api/dashboard/top-query/experiments/brands/{brand}` | Bearer；路径品牌 | 实验列表 |
| GET | `/api/dashboard/top-query/experiments/brands/{brand}/sample-pool` | Bearer；路径品牌 | 候选池 |
| GET | `/api/dashboard/top-query/experiments/{experiment_id}` | Bearer；实验所属品牌 | 实验详情 |
| GET | `/api/dashboard/top-query/experiments/{experiment_id}/report` | Bearer；实验所属品牌 | 实验报告 |
| GET | `/api/dashboard/top-query/experiments/{experiment_id}/export` | Bearer；实验所属品牌 | 文件导出 |

通用请求、响应和错误见[03 通用协议、错误与流式传输](03-通用协议与错误契约.md)；实验写入和内部快照导出的执行契约见[04 内部写入与执行契约](04-内部写入与执行契约.md)。日期参数均为 ISO `YYYY-MM-DD`。当前没有 `response_model`；统计明细、质量对象和治理对象内部未逐字段承诺的部分均为扩展区。

## 2. 列表与候选池

### 2.1 `GET /api/dashboard/top-query/experiments/brands/{brand}`

#### 请求

- Path：`brand`，必填且必须在授权范围。
- Query：`status?`、`startDate?`、`endDate?`、`page?`（默认 1，最小 1）、`pageSize?`（默认 20，范围 1–100）。

#### 成功响应

返回 `{brand,current,items,total,page,pageSize}`。`current` 为当前页中首个 `draft/scheduled/running` 实验，可能为 `null`。

`items[]` 含 `id,brand,experimentName,status,sampleDataDate,plannedStartDate,plannedEndDate,startedAt,endedAt,createdBy,treatmentCount,controlCount,quality`；日期字段可为 `null`，`quality` 为扩展区。

### 2.2 `GET /api/dashboard/top-query/experiments/brands/{brand}/sample-pool`

#### 请求

- Path：`brand`，必填且必须在授权范围。
- Query：`today?`，ISO 日期；`limit?` 默认 150，范围 1–500。

#### 成功响应

返回 `{brand,sampleDataDate,items}`。`items[]` 含 `queryText,governanceKey,queryRank,searchUv,searchPv,ctr,cvr,avgCtr,avgCvr,queryPvShare`。

#### 错误

无可用快照时返回 `400`，不是空候选池。

#### 调用示例

```bash
curl --fail-with-body \
  'https://ops.example.test/api/dashboard/top-query/experiments/brands/atlas/sample-pool?limit=150' \
  -H 'Authorization: Bearer <issued-jwt>'
```

## 3. 实验详情与分析

### 3.1 `GET /api/dashboard/top-query/experiments/{experiment_id}`

#### 请求

- Path：`experiment_id`，整数；按实验所属品牌校验。
- Query：`asOfDate?`，ISO 日期；只纳入该日及之前的日指标。

#### 成功响应

返回实验基础字段 `id,brand,experimentName,status,sampleDataDate,plannedStartDate,plannedEndDate,baselineStartDate,baselineEndDate,baselineLockedAt,calculationVersion,startedAt,endedAt,createdBy,samples,items,dataQuality,groupSummary`。

`samples[]` 与 `items[]` 的指标字段以当前实现为准；最新指标和治理字段可为 `null`。`dataQuality` 可为 `null`，质量不完整时 `groupSummary` 可为空对象。

### 3.2 `GET /api/dashboard/top-query/experiments/{experiment_id}/report`

#### 请求

- Path：`experiment_id`，整数；按实验所属品牌校验。
- 无额外必填参数。

#### 成功响应

稳定顶层为 `experiment,calculationVersion,generatedAt,timezone,reportDate,baselineQuality,operations,trend,queries,queryDailyMetrics,baselineEvidence,actions,dataStartDate,dataEndDate,dataDays,overview,reportSnapshotToken`。

`reportSnapshotToken` 仅供内部快照导出流程使用，不是通用并发或幂等协议；分析数组结构属于扩展区。

原独立 `overview`、`trend`、`queries` 接口已退役，调用方从本报告同名字段读取。

## 4. 导出

### 4.1 `GET /api/dashboard/top-query/experiments/{experiment_id}/export`

#### 请求

- Path：`experiment_id`，整数；按实验所属品牌校验。
- Query：`format` 必填，取 `csv`、`zip`、`xlsx`，大小写会归一化。

#### 成功响应

返回二进制 body，并设置 `Content-Disposition: attachment` 和对应 `Content-Type`；不是 JSON envelope。

#### 错误与重试

非法格式返回 `400`；下载网络中断可按 GET 有限重试，但不能把中断文件当作完整文件。

#### 调用示例

```bash
curl --fail-with-body -L \
  'https://ops.example.test/api/dashboard/top-query/experiments/42/export?format=csv' \
  -H 'Authorization: Bearer <issued-jwt>' \
  -o experiment-42.csv
```

## 5. 内部接口索引

| 方法 | 路径 | 用途 | 主要边界 |
| --- | --- | --- | --- |
| POST | `/api/dashboard/top-query/experiments/brands/{brand}/draft` | 创建或替换草稿 | 需品牌配置权限；样本组必须通过实验校验。 |
| POST | `/api/dashboard/top-query/experiments/{experiment_id}/schedule` | 将草稿转为计划状态 | 按实验所属品牌和配置权限校验。 |
| POST | `/api/dashboard/top-query/experiments/{experiment_id}/end` | 结束实验 | 状态不允许时返回 `400`。 |
| POST | `/api/dashboard/top-query/experiments/{experiment_id}/cancel` | 取消实验 | 状态不允许时返回 `400`。 |
| POST | `/api/dashboard/top-query/experiments/{experiment_id}/export` | 导出已固化报告快照 | body 必须含 `format,snapshotToken`；仅供管理端流程。 |

外部调用方只能使用本页 GET，不得调用带 `reportSnapshotToken` 的 POST 导出流程。该 POST 的请求身份、快照前置和失败恢复见 04。
