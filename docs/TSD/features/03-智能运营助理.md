# 智能运营助理

## 1. 模块定位

智能运营助理由 PI Agent 驱动，面向运营人员提供昨日自动化运营状态、Top Query、无结果词、异常和治理动作的可执行诊断。PI Agent 负责语义理解、步骤规划、工具调用和结果总结；确定性的治理主链、权限和动作网关仍由 AIOPS 负责。

## 2. 运行链路

```text
运营人员打开 PI Web 工作台
-> AIOPS 鉴权并注入账号权限范围
-> 项目内 PI SDK Session
-> PI 业务工具通过内部受保护接口读取 AIOPS 事实
-> read / bash / grep / find 读取本地工作区
-> write / edit 或本地 API 执行测试环境操作
-> 工具结果与证据流式回传
-> prepare -> confirm / cancel（业务写操作）
-> AIOPS 持久化会话和审计
```

- `assistant.chat` 节点固定使用 `pi_agent` 通道。
- `pi-runtime` 是独立 Node 服务，直接调用 `@earendil-works/pi-coding-agent` SDK；FastAPI 不启动 `pi --mode rpc` CLI。
- PI SDK 的 `SessionManager` 使用 AIOPS `sessionId` 持久化会话，会话文件位于 `PI_AGENT_SESSION_DIR`。
- PI 业务工具通过 `POST /api/internal/assistant/tools/{tool_name}` 调用 `AssistantToolService`；接口要求 `X-PI-Internal-Token`，并按 `userId` 重新解析账号权限。
- 页面历史、账号权限、动作状态和审计记录以 AIOPS 数据库为准；品牌仅作为数据库权限过滤维度，不作为页面概念。
- 非平台管理员的助理品牌范围直接读取 `User.brand_permissions`；`AssistantUserBinding` 历史记录不再参与可访问 Binding、会话或动作鉴权。品牌空间和 Agent Binding 仍用于解析可用运行配置，暂不做表结构迁移。

## 3. 能力与工具

| 能力 | 实现 |
| --- | --- |
| 运营上下文 | AIOPS 在请求前按用户品牌聚合昨日任务、Query、事件、异常和动作上下文。 |
| 本地事实查询 | PI 原生 `read`、`grep`、`find`、`bash` 调用账号工作区内的本地接口。 |
| AIOPS 业务事实 | PI 自定义工具 `read_today_context`、`read_brand_metrics`、`read_top_query_*`、`read_abnormal_query_logs`、`read_inventory_monitoring`、`search_products`、`get_product_detail` 通过内部接口读取数据库和受控业务服务。 |
| 文件与脚本执行 | PI 原生 `write`、`edit`、`bash`，用于本地测试环境检查和修复。 |
| 业务动作 | 仅通过 AIOPS `prepare`、`confirm`、`cancel`，保留权限、审计、回读和回滚。 |
| 流式事件 | 转换 `message_update`、`tool_execution_*`、`agent_end` 和错误事件为 AIOPS SSE 事件。 |

## 4. 状态与异常

- 账号 `brand_permissions` 是助理会话、上下文、工具和动作的唯一用户品牌授权来源；页面不允许通过参数或历史绑定绕过账号权限。
- 账号品牌被移除后，会话列表、会话维护和动作链路立即拒绝该品牌；已有 `agent_binding_id` 只校验 Binding/品牌空间仍启用且与会话品牌一致。
- PI SDK runtime 未启动、模型未配置、超时、断线或缺少 `agent_end` 时返回明确失败状态，不伪造业务结果。
- `assistant.chat` 优先使用已发布的节点模型；未显式配置 `PI_AGENT_PROVIDER` 时，runtime 可使用已有 `RD_LLM_BASE_URL` 与 `RD_LLM_API_KEY` 生成 `aiops-gateway` Provider，并将当前已发布模型动态合并到 PI `models.json`。
- 显式配置 `PI_AGENT_PROVIDER` 时必须同时配置匹配的 `PI_AGENT_MODEL`；缺少认证或 Provider/Model 不匹配时，页面显示可操作的配置错误，不暴露本地路径。
- 已有 Session 可恢复时继续执行；恢复失败时页面提示上下文未恢复并允许重试。
- 工具结果记录工具名、参数摘要、结果摘要和错误，不记录密钥或原始内部对象。

## 5. 前端页面

`/smart-assistant` 采用 Codex 式会话界面：左侧会话列表只显示会话标题和会话操作，右侧为居中、内容优先的对话流与底部输入框，在 AIOPS React 应用内实现并保留 AIOPS 登录态、账号权限上下文、动作卡片和会话历史。流式回答、工具执行过程、失败原因和人工接管提示内联在消息流中展示，不展示品牌选择、品牌标签、项目工作区、终端或运行时检查器。

执行过程由消息内的工具调用块呈现；PI 原生 `read`、`write`、`edit`、`bash`、`grep`、`find` 能力仍在后端运行时开启，不在页面暴露为独立面板。
