# Enums and States

## 动作事实链状态

`action_attempt.status` 的状态机由 `src/governance/action_gateway.py` 负责：`persisted → executing → success/failed`；过期 execution 必须先由数据库单赢家进入 `fencing`，持久化绑定 request ID、generation 和 fence token 的 `action_fence_evidence` 后才能进入 `execution_unknown`；权威回读 claim 进入 `reconciling`，最终由唯一 `action_terminal_fact` 收口为 `success`、`failed` 或 `inconclusive`。execution、fence 和 readback claim 都受 `version + claim_token + lease_expires_at` 条件更新保护；租约默认使用数据库 `CURRENT_TIMESTAMP`，配置必须为正整数。

## 调度运行与 Leader 租约

这两张表的状态由调度持久化层解释，不能把运行状态和 Leader 租约状态混为一谈。

| 表/字段 | 已确认取值或默认 | 约束要点 | 来源 |
|---|---|---|---|
| scheduler_job_run.status | 默认 planned；planned / claimed / running / succeeded / failed / execution_unknown | 状态与 attempt、claim、生命周期时间列必须满足同一组 state facts。 | `src/persistence/models.py` |
| scheduler_job_run.attempt_no | 默认 0；非负整数 | planned 为 0，取得 claim 后必须大于 0。 | `src/persistence/models.py` |
| scheduler_leader_lease.status | 默认 active；active / released | active 必须有有效租约时间且 released_at 为空；released 必须有 released_at。 | `src/persistence/models.py` |
| scheduler_leader_lease.fencing_token | 无默认；正整数 | 由 Leader 租约单调递增，用于保护调度运行写入。 | `src/persistence/models.py`、`src/persistence/repositories.py` |

## 状态维护规则

新增或修改状态时，同时检查模型 CHECK 约束、状态机实现、API 展示和迁移验证；如果源码只声明字符串字段而没有完整取值约束，保留“待业务确认”，不要把页面文案当成数据库枚举。

其它 status、display_status、stage、event_type、mode、*_status 是字符串字段，ORM 无 CHECK 约束；完整取值由应用状态机决定，未从源码确认者为“待业务确认”。新增状态必须同步调用方、API 展示和回归验证。

last_check_stock 为历史名称，当前存储最近断码率百分比整数，不是库存件数。
