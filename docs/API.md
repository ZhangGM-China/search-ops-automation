# 外部依赖与数据源文档总纲

`docs/api/` 只记录本系统调用的外部业务系统、模型服务、数据源数据库、通知与知识图谱依赖。它不是本系统 FastAPI 的接口契约，也不承载本地治理库 schema。

## 目录导航

| 文档 | 内容 | 使用场景 |
| --- | --- | --- |
| [01 外部业务系统接口](api/01-外部业务系统接口.md) | 搜索、商品、拉黑、降桶、标签分桶、尺码与热词 | `OperationalService` 联调与排障 |
| [02 外部模型与第三方依赖](api/02-外部模型与第三方依赖.md) | LLM、模型请求/响应及第三方服务 | 模型调用与依赖排障 |
| [03 生产数据源数据库与 SQL 规则](api/03-生产数据源数据库与SQL规则.md) | 品牌指标、Top Query 与数据源 SQL | 只读抽取、指标核对 |
| [04 飞书通知](api/04-飞书通知.md) | 日报与告警机器人 | 通知链路排障 |

## 边界与维护

- 本系统 FastAPI、认证、品牌隔离、外部只读 allowlist 与内部接口 inventory：见 [TSD 接口设计](TSD/04-接口设计.md)。
- 本地治理持久化、表结构和环境运行约束：见 [TSD 数据存储设计](TSD/03-数据存储设计.md) 与 [TSD 运行、恢复与发布边界](TSD/07-兼容性灰度与运维.md)。
- 外部依赖字段、地址或调用规则变更时，只更新相应的 `docs/api/0x-*.md`；本系统路由契约变更不得回写到本目录。
- 本目录含联调所需的原始连接/鉴权资料，按项目访问控制处理；新文档示例使用占位符。
