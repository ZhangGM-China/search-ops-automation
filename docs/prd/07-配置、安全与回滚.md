# 配置、安全与回滚

## 1. 配置

- Query 筛选、召回、排序、相关性、断码和模型并发等阈值支持品牌或全局配置。
- KG Agent、世界知识 Agent 和相关性多模态 Agent 的主/备模型可在前端配置。
- 模型名支持运营直接填写；系统不按模型能力白名单阻止保存。是否支持节点所需的图文输入由配置人员确认，页面保留图文需求提示。
- 配置保存后热加载；运行中的任务不受影响，新任务读取新配置。
- 配置缺失或无效时当前节点记异常或跳过，不自动扩大写入范围。

## 2. 安全

- 所有外部写入经过品牌权限、动作权限、幂等、审计和权威回读。
- 测试环境默认运行；生产操作必须显式授权。
- 模型、图片和业务输入按脱敏规则处理，密钥只从 Secret 注入。

## 3. 回滚与异常

- 请求成功不等于写入成功，回读失败记异常。
- 外部动作结果未知时先查询真实状态，不重复写入。
- 单个 Query 或节点失败不阻塞后续节点；失败原因和影响范围向前端暴露。

## 4. 验收场景

- Given 新配置已保存，When 新任务启动，Then 使用新配置；运行中任务继续使用启动时配置。
