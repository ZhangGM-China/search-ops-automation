# 世界知识与标签桶治理

## 1. 规则

- 项目内事实服务统一读取季节、节日、天气等共享事实；品牌趋势单独读取。
- 单个事实未读取到时记录警告，使用其他正常事实继续。
- 所有事实均未读取到时当前节点记异常并跳过，继续相关性节点。
- 世界知识结论只使用执行、跳过、异常三种对用户可理解的结果；动作仍经过统一权限、幂等、回读和审计。

## 2. 相关文档

完整规则以[Query 治理重构计划](../Query%20治理重构计划.md)第 4.5 节为准。

## 3. 验收场景

- Given 一个事实读取失败但其他事实可用，When 世界知识节点执行，Then 显示警告并使用可用事实继续。
- Given 所有事实均不可用，When 世界知识节点执行，Then 记录异常并继续相关性节点。
