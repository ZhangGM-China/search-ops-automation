# 断码风险判断、降桶与恢复

| 字段 | 日期 |
| --- | --- |

## 1. 范围

断码是独立周期任务，不进入 Query 治理主链。巡检周期、断码率阈值和每次检查的 Top N 均可配置并支持热加载。

## 2. 周期流程

1. 读取品牌最新已持久化的 Top Query 批次和断码监测列表。
2. 对每个 Query 调用 Mixed 获取实时 Top N。
3. 调用商品 list 接口批量检查商品是否存在；存在时检查是否上架。不存在或已下架的商品停止监测。
4. 执行现有分桶资格检查，不允许断码的分桶直接跳过。
5. 对允许处理的商品计算断码率，达到阈值时降桶；写入成功并回读后加入监测列表。
6. 商品恢复且断码率低于阈值时移除降桶并回读，标记恢复。
7. 状态接口整体失败或尺码查询失败时保留原状态并记录异常。

每轮动作后重新调用 Mixed，只检查新进入 Top N 的商品；已处理商品不重复检查。最大循环次数由配置控制。

## 3. 展示

断码巡检和恢复记录仍在 Query 治理页面展示为多次记录，但不计入主链节点状态。

## 5. 验收场景

- Given 当天断码独立周期任务成功完成一轮巡检，When 某 Query 未发现断码商品，Then Query 仍展示“断码”节点、已执行状态和 0 个断码商品。
- Given 商品不存在或已下架，When 批量状态检查完成，Then 停止该商品监测。
- Given 商品恢复且断码率低于阈值，When 恢复动作回读成功，Then 标记恢复并保留巡检记录。
