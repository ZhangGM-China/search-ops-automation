## 1. 追踪范围

记录 Top Query 批次、Query、节点、动作、回读、模型调用和异常。健康评分与独立评估 Agent 已退役，不作为主链收口条件。

## 2. 页面与指标

- 页面展示治理前 S0、当前实时结果、五种节点状态、动作记录、回读结果和异常说明。
- 断码巡检记录作为独立周期记录展示，不并入主链状态。
- A/B Test 按实验组完整治理、对照组只记录数据变化，沿用实验指标口径。
- 运行耗时、Token、动作数量和失败数量按批次、Query、节点分别统计。

## 3. 异常

数据不足、模型失败、外部写入失败和回读失败必须明确记录。单个 Query 或节点异常不阻塞其他 Query 和后续节点。

## 4. 相关文档

状态与字段以[Query 治理重构计划](../Query%20治理重构计划.md)、[Query 治理接口](../TSD/api/06-Query治理接口.md)和[联调测试与规范](../TSD/08-联调测试与规范.md)为准。

## 5. 验收场景

- Given 节点或动作失败，When 用户查看详情，Then 能看到异常说明、耗时和回读结果，且其他 Query 不受阻塞。
