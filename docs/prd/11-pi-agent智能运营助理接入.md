# PI Agent 智能运营助理

| 字段 | 日期 |

## 1. 模块目标

为运营人员提供围绕昨日自动化运营、品牌指标、Top Query、无结果词、治理动作和异常日志的可执行 Agent。PI Agent 负责理解请求、规划步骤、调用工具、执行诊断、读取结果并总结证据；每日治理主链仍由确定性代码执行。

## 2. 运行方式

- PI Agent 是智能运营助理唯一运行时，通过项目内 Node SDK runtime、Session 和工具机制接入；应用不依赖用户安装或执行 PI CLI。
- `ENV=test` 下开放 PI 原生 `read`、`write`、`edit`、`bash`、`grep`、`find`、`ls`，并允许访问本地数据库接口、AIOPS API、测试服务和项目文件。
- 会话使用 AIOPS `sessionId` 映射到 PI SDK 的 `SessionManager`，PI Session 文件用于恢复执行上下文；AIOPS 数据库中的会话记录仍是页面历史和审计事实。
- 工具调用、结果、错误和 Agent 完成事件必须回传页面并落入会话日志。

## 3. 权限与动作

- 身份、账号可访问的数据范围和会话归属由 AIOPS API 校验后再启动 Agent；页面不提供品牌选择器。
- 助理品牌范围唯一继承账号 `brandPermissions`，账号管理页不再提供独立助理授权；历史用户绑定数据不参与运行时鉴权。
- 读操作可由 PI 直接调用本地数据库接口、AIOPS API 或 Shell 完成，返回结构化结果和证据。
- 业务写操作必须调用现有 `prepare -> confirm / cancel` 链路，继续执行权限检查、动作审计、回读验证和回滚；PI 不得绕过动作网关直接写业务数据。
- 密钥和凭据不得进入提示词、会话内容、工具日志或页面。

## 4. 页面要求

`/smart-assistant` 使用 Codex 式会话界面，左侧会话列表只显示会话标题，右侧为居中、内容优先的对话流与底部输入框，保留 AIOPS 登录态和业务上下文，并支持：

- 昨日自动化运营概览、失败原因和 Query 处理轨迹；
- PI Agent 流式文本、工具调用、工具结果、错误和完成状态；
- 会话列表、恢复、重命名、置顶、删除和重试；
- 账号权限上下文、证据摘要、动作风险、人工接管和确认入口。

页面不展示品牌选择、品牌标签、项目工作区、终端或运行时检查器；PI 原生工具能力保留在运行时，通过消息内的工具调用块回传执行过程。

## 5. 会话与异常

- 账号品牌权限决定 PI 可调用的品牌数据、历史会话和工具范围；增删账号品牌权限后立即生效，用户无需在页面切换品牌。
- PI SDK runtime 未启动、模型未配置、超时、断线或未返回 `agent_end` 时，页面展示失败状态，可重试，不伪造业务结果。
- PI Session 可恢复时继续原会话；恢复失败时创建新会话并明确提示上下文未恢复。
- 工具失败必须保留工具名、错误摘要和已完成步骤，证据不足时转人工。

## 6. 验收标准

1. 旧运行时包、进程、配置、环境变量、凭据引用、代码、数据库专属字段/迁移、测试和文档均已退役，全量检索无活动引用。
2. PI Agent SDK runtime 在本地测试环境可启动、创建和恢复固定 Session，且原生工具可调用数据库接口、AIOPS API、Shell、文件读写和测试服务；工具调用前后均执行账号权限拦截。
3. `/smart-assistant` 页面完成 PI Web 工作台改造，可展示昨日运营状态、工具执行过程、结构化结果、失败原因和人工接管提示。
4. 业务写操作仍经过权限、prepare、confirm/cancel、审计、回读和回滚链路。
5. 后端单元/集成、前端类型检查/构建、关键 E2E 和本地浏览器验证均有可复核证据。
