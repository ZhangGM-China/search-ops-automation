## 1. 产品定位

系统面向搜索运营人员，持续发现并治理品牌 Top Query 的召回、排序和相关性问题，记录动作、验证和异常。无结果词、智能助理和 A/B Test 是独立协作模块。

## 2. 当前范围

- Query 治理主链：提取 Query、保存 S0、召回检查、排序治理、相关性检测、主链结束。
- KG Agent：承接召回异常和相关性批量拉黑的异步图谱调整方案。
- 断码：独立周期巡检、降桶和恢复，仍在 Query 治理页面展示。
- A/B Test：实验组执行治理，对照组只记录数据变化。
- 价格治理、健康评分、Evaluator、旧 Agent Loop 和 Ops Team 已退役。

## 3. 用户输出

页面展示治理前 S0、实时商品结果、节点状态、动作记录、回读结果、异常说明、断码巡检记录和 A/B Test 观测指标。

## 4. 相关文档

完整业务规则以[Query 治理重构计划](../Query%20治理重构计划.md)和对应 TSD/API 文档为准。

## 5. 验收场景

- Given 用户进入 Query 治理页面，When 查看治理结果，Then 能区分 S0、实时结果、节点状态和动作记录。
