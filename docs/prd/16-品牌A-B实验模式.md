# 品牌治理效果对照观察

| 字段 | 日期 |
| --- | --- |
| 创建时间 | 2026-07-23 |
| 最后更新时间 | 2026-08-31 |

## 1. 目标与范围

比较固定实验组与对照组在同一观察期内的搜索指标变化。实验组执行完整 Query 治理，对照组只记录自然数据变化，不执行任何治理动作。

## 2. 样本与生命周期

- 每个实验固定 20 个实验组 Query 和 20 个对照组 Query，样本、品牌和观察日期锁定。
- 实验生命周期为 `draft → scheduled → running → ended`；样本不在运行中更换。
- 两组 Query 身份必须唯一，数据缺失、样本错配或对照污染时标记异常，不输出正常结论。

## 3. 日常运行

每日读取锁定样本：实验组进入确定性主链，对照组只读取并保存指标。实验组动作、节点状态和验证事实关联到实验指标；对照组不得创建治理任务、动作或人工处理记录。

## 4. 结果与展示

按真实 Search UV、CTR、CVR 等分子分母计算两组变化差异。结果用于运营观察，不宣称严格因果结论。页面和导出展示样本质量、治理覆盖、指标变化和异常说明。

## 5. 相关文档

实现边界以[Query 治理重构计划](../Query%20治理重构计划.md)第 4.12 节和[品牌 A/B 实验技术设计](../TSD/features/04-品牌A-B实验.md)为准。

## 6. 验收场景

- Given 实验已运行，When 每日任务执行，Then 实验组治理、对照组只观测且对照组无治理动作。
- Given 样本缺失或对照污染，When 日指标收口，Then 标记异常且不输出正常效果结论。
